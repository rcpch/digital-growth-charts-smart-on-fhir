# RCPCH Digital Growth Charts SMART on FHIR app

> [!WARNING]  
> This project is a work in progress. Do not use any part of this in a production clinical setting
> and be aware that any SNOMED/LOINC codings used may change at any time. Thanks!

Plug and play integration with SMART on FHIR EHR systems for [RCPCH Digital Growth Charts](https://growth.rcpch.ac.uk/).

## Getting started

1. Node 22 (eg `nvm use`)
1. `npm install`
1. `npm run dev`
1.
